# decathlon-excel-dashboard

An interactive dashboard analyzing Decathlon's sales performance, order and customer behavior — built to turn raw sales data into smarter insights, stronger connections, and better performance.

## 📊 Overview

This dashboard provides a 360° view of sales and customer metrics across 2024–2026, helping identify top-performing sports categories, seasonal trends, and customer retention patterns.

## 🔑 Key Metrics

- **Total Sales:** ₹36.7 Cr (▲ 40.8%)
- **Total Orders:** 30,000 (▲ 40.1%)
- **Total Customers:** 8,998 (▲ 13.5%)
- **Average Order Value:** ₹12,236 (▲ 0.5%)
- **Customer Retention Rate:** 64.58%

## 📈 Dashboard Features

- **Sales Over Time** – Monthly sales trend visualization
- **Sales by Product Category** – Breakdown across Badminton, Camping, Cricket, Cycling, Fitness, Football, Running, Swimming, and Trekking
- **Customer Retention Rate** – Monthly retention trend analysis
- **Sales by Gender** – Customer segmentation (50% Male, 50% Female)
- **Year Filter** – Toggle between 2024, 2025, and 2026 data

## 🛠️ Tools Used

- Microsoft Excel (Power Query, Pivot Tables, Charts, Slicers, Dashboard Design)

## 📂 Files

- `Decathlon_Synthetic_Data_30000.xlsx` – Main Excel dashboard file
- `dashboard.png` – Dashboard preview

## 🚀 How to Use

1. Clone this repository
2. Open the `.xlsx` file in Microsoft Excel
3. Use the Year filter to explore data across 2024, 2025, and 2026
